One original one-liner for make.fun's "One Line, One Laugh" bounty ($2 in USDC). The program writes the line to `/output/entry.txt`.

> We used a Ouija board to contact my dead grandfather. He spelled out: 'STOP USING MY WIFI.'

## Run it

```sh
node main.ts
```

Set `OUTPUT_DIR` to write `entry.txt` somewhere else (for local testing).
